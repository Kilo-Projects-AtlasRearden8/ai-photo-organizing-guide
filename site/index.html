    Organizing Your Digital Photos with Free AI Tools

    A beginner-friendly, privacy-first manual for sorting, renaming, deduplicating, and backing up your photos — without ever uploading them to the cloud.

    Privacy First: Every tool in this guide runs locally on your computer. Your photos never leave your hard drive.

    About This Guide

    Written for anyone with a folder full of photos named like IMG_4829.jpg and no idea where to start. No coding experience required. Everything here is free, local, and private.

    Step 1: Gather Your Photos

    Collect all photos into one working folder before organizing. Photos often live in multiple places — phone backups, SD cards, downloads folder, etc. 

    mkdir -p ~/Photos/Organizing

    Copy all photos into this folder. Don't move them yet — copy them.

    find ~/Photos/Organizing -type f \( -iname "*.jpg" -o -iname "*.jpeg" -o -iname "*.png" \) | wc -l

    Step 2: Sort by Date

    Most photos contain EXIF metadata with the date they were taken. ExifTool can organize them into year/month folders automatically. 

    exiftool -d "%Y/%Y-%m/%Y-%m-%d" -Directory<DateTimeOriginal -r ~/Photos/Organizing

    Photos without EXIF dates will be skipped. Place them in an Undated/ folder for manual review.

    Step 3: Sort by Event

    Group photos by occasion — birthdays, vacations, holidays. Use tags in DigiKam or create event folders manually.

    • Import your folder into DigiKam
    • Add tags like "Summer Vacation 2024" or "Sarah's Birthday"
    • Or create folders: mkdir "Birthday Party" "Beach Trip"

    Step 4: Sort by People (Face Detection)

    Face detection runs entirely on your computer. No facial data is sent anywhere.

    • DigiKam: Tools → Maintain → Face Detection
    • PhotoPrism: Run locally via Docker
    docker run --name photoprism -d \
  -p 2342:2342 \
  -v ~/Photos:/photos \
  photoprism/photoprism

    Then open http://localhost:2342 in your browser.

    Step 5: Rename Your Files

    Replace names like IMG_4829.jpg with meaningful names: 2024-03-15_Sarahs-Birthday_001.jpg 

    exiftool '-FileName<DateTimeOriginal' -d "%Y-%m-%d_%%c.%%e" -r ~/Photos/Organizing

    Or use the included Python script: python3 scripts/rename_photos.py --folder ~/Photos/Organizing --event "Summer Vacation"

    Step 6: Remove Duplicates

    Find and remove exact duplicate files to save space and reduce clutter. 

    fdupes -r ~/Photos/Organizing

    Review before deleting. Use fdupes -rd to delete interactively, choosing which copy to keep.

    Step 7: Create Backups

    Follow the 3-2-1 rule: 3 copies, 2 media types, 1 offsite. 

    rsync -av --delete ~/Photos/Organizing/ /Volumes/ExternalDrive/Photos-Backup/

    For encrypted backups: borg init --encryption repokey /Volumes/ExternalDrive/Backups/photos

    Cloud warning: If you use cloud storage, encrypt before uploading. Never upload unencrypted sensitive photos.

    Troubleshooting & FAQ

    My photos don't have dates. What do I do?

    Use the file modification date as a fallback, or organize by event manually.

    Can I undo a rename?

    ExifTool creates backup files (_original). Restore with: exiftool -restore_original

    Is face detection safe?

    Yes — when it runs locally. DigiKam and PhotoPrism process faces on your computer only.

    How often should I back up?

    After each organizing session, and weekly thereafter.
