# AI Photo Organizing Guide

A beginner-friendly manual for organizing digital photos using free, local AI tools — never uploading your sensitive photos to the cloud.

## What This Guide Covers

- **Sorting by date, event, and people** using local AI models
- **Renaming files** with meaningful, consistent names
- **Removing duplicates** safely and efficiently
- **Creating backups** that actually protect your memories
- **Privacy-first workflow** — your photos never leave your computer

## Who This Is For

Anyone with a messy photo collection who wants to organize it without handing their personal memories to big tech companies. No coding experience required.

## Quick Start

1. Read the [Manual](docs/manual.md) for the complete step-by-step guide
2. Print the [Workflow Checklist](docs/checklist.md) to follow along
3. Open [site/index.html](site/index.html) in your browser for an interactive version

## Tools Used (All Free & Local)

- **ExifTool** — read/write photo metadata
- **fdupes** / **rdfind** — find duplicate files
- **DigiKam** / **PhotoPrism** (local) — AI face/event detection
- **rsync** / **borgbackup** — reliable backups
- **Python scripts** (included) — automation helpers
